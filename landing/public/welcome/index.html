I just added the Chrome Relay extension (github.com/kiluazen/chrome-relay) —
an open-source, fully local tool that drives my real Chrome from the terminal.

Set it up for me:
  npm i -g chrome-relay
  chrome-relay install      # registers the local bridge
  chrome-relay doctor       # verify the connection
  npx skills add kiluazen/kstack@chrome-relay   # learn the commands

Then run chrome-relay tabs and show me my open tabs.

Stuck? Read the install docs.
